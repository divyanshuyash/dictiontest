# Diction

A cinematic, globe-led lead-generation website for Diction and the KNOWN masterclass.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The loading screen opens into the interactive Diction globe, which transitions in place into the photographic hero as the visitor scrolls.

Primary routes:

- `/` — loading screen, globe intro and hero
- `/known` — KNOWN masterclass and registration
- `/thank-you` — registration confirmation and WhatsApp reminder handoff
